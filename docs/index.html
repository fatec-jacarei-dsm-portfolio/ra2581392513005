Projetos acadêmicos

ABP - 1º Semestre (1º Semestre de 2025)

No primeiro semestre na Fatec Jacareí, eu fiz uma equipe de 7 pessoas contando comigo aonde fomos designados a criar um site simulando uma interface de gestão acadêmica para ser utilizada pelos alunos e funcionários da instituição. Aonde os alunos podem ver os horários de aula, o mapeamento e informações sobre seus próprios professores.
A minha parte no projeto foi a da criação da tela aonde os alunos podem ver o horário de aula dependend de qual curso é o escolhido, aonde tive de utilizar HTML e CSS para criar uma estrutura parecida com a que me foi passada, e o uso de Javascript para que seja acessado diretamente do banco de dados e mostrar quais as aulas que serão passadas na turma escolhida de segunda-feira até sexta-feira.
Felizmente graças ao esforço e a nossa apresentação, nossa equipe ficou em 1º lugar dentre as mais bem avaliadas no 1º semestre, e espero que esse sucesso também aconteça nos próximos semestres.
Projeto ABP 1º semestre


ABP - 2º Semestre (2º Semestre de 2025)

No 2º semestre já foi um pouco mais diferente, ao invés de 7 membros agora eram 6 membros, e passamos a utilizar ferramentas como React, Docker e Typescript em nosso projeto. Dessa vez o projeto era uma aplicação web para a visualização e disseminação de dados limnológicos, aonde esses dados eram coletados em reservatórios da Furnas Centrais Elétricas S.A. em cooperação com o INPE, UFRJ, UFJF e IIE.
Dessa vez eu tive de trabalhar em mais áreas em comparação com o 1º semestre, ficando responsável na 1ª sprint pela API criando vários arquivos para cada tabela no banco de dados e seu funcionamento; na 2ª sprint trabalhando no mapa e sua filtragem, utilizando principalmente a API desenvolvida anteriormente; e na 3ª sprint trabalhando com os gráficos e procurava por possíveis bugs e testes finais antes de apresentar o projeto.
Projeto ABP 2º semestre


ABP - 3º Semestre (1º Semestre de 2026)

No 3º semestre eu fiz parte do projeto Valle Leads System, que era um sistema de gestão de leads para a 1000 Valle Multimarcas, utilizando tecnologias como React, Vite e Typescript para Frontend, Node.js, Typescript e Express no Backend, Tailwind CSS para a estilização, PostgreSQL no banco de dados, Prisma ORM, Docker, Docker Compose e Nginx.
Minha participação teve como foco a criação da estrutura inicial do backend, criação do schema prisma com as tabelas, relações, índices e UUID por exemplo e o DTO das negociações com ZOD na primeira sprint. Depois na segunda sprint, acabei refatorando e criando os arquivos dos usuários e clientes da aplicação. Por fim na terceira sprint removi todos os dados mockados da lista de usuários, integrei com os dados reais do banco, fiz ajustes na lógica e então refatorei e melhorei na estilização da página de usuários.
